Building Nomisma

The first repository: cmake_template

2 October 20262 min read

The first repository in Nomisma Labs is cmake_template. Before I start adding trading components, I want a repeatable way to build, test and connect them.

Configuration, logging and the machinery for connecting components have different jobs, but they share the same basic needs: a build system, tests, dependency handling and a way to be used by another project. Settling those things once makes creating a component a mundane operation. I want to spend my attention on the component's own purpose.

Nomisma takes the ideas from my earlier trading-platform project to the next level: componentisation of trading software and commoditisation of the C++ development workflow. Creating a library, adding a test or integrating a dependency should be a familiar, repeatable part of development.

The cmake_template repo has two jobs. It provides the structure for a new repository, and it gives me a dedicated place to try build system, dependencies and C++ features before other components use them. C++20 modules are the first substantial experiment there.

Separate repositories also let the shared build infrastructure evolve independently. Each component keeps its own build infrastructure and pinned dependency revisions. New versions of the build system and dependencies can be introduced and tested in the template without automatically changing existing components. Each component adopts an update when it is ready to validate it.

The template uses the latest C++ standard and stable library versions supported by the toolchain, alongside common CMake helpers and presets for development, release builds, sanitizers and CI. Formatting, naming and licence checks establish shared conventions, with guidance for both developers and coding agents.

A small example library and application exercise the shared build infrastructure. Unit and integration test coverage helps catch regressions and gives me confidence that components remain usable in other projects as that infrastructure evolves.
